# PHYS 1251 Final Prep

A free study app for UGA PHYS 1251 (Intro Studio Physics for Engineers I, Fall 2026), built from the course's eLC materials: midterm replays, a problem generator with hints and worked solutions, timed mock finals, a method picker, the annotated formula sheet and a day-by-day study plan.

**Open it:** https://wmb70399.github.io/phys1251-final/

Progress is saved privately in each person's own browser. Use *Profile & backup* to move it to another device. Not an official UGA site.
